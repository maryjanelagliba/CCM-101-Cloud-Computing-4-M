# Cloud Provider Comparison

| Infrastructure Component                 | AWS                                                                | Microsoft Azure                                                                      | Google Cloud Platform                                                      |
| ---------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| **Compute**                              | Amazon EC2, AWS Lambda, Amazon ECS, Elastic Beanstalk              | Azure Virtual Machines, Azure Functions, App Service, Azure Kubernetes Service (AKS) | Compute Engine, Cloud Run, App Engine, Google Kubernetes Engine (GKE)      |
| **Storage**                              | Amazon S3, Amazon EBS, Amazon EFS                                  | Azure Blob Storage, Azure Managed Disks, Azure Files                                 | Cloud Storage, Persistent Disk, Filestore                                  |
| **Networking**                           | Amazon VPC, Elastic Load Balancing, CloudFront, AWS Direct Connect | Azure Virtual Network, Azure Load Balancer, Azure Front Door, ExpressRoute           | Virtual Private Cloud, Cloud Load Balancing, Cloud CDN, Cloud Interconnect |
| **Identity and Access Management (IAM)** | AWS IAM, IAM Policies, IAM Roles                                   | Microsoft Entra ID, Azure RBAC, Managed Identities                                   | Cloud IAM, Cloud Identity, IAM Roles                                       |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS is a strong choice for the provider with the widest variety of cloud services. It offers numerous tools for application development, computing, databases, storage, networking, security, analytics, monitoring, and artificial intelligence. Its large selection allows businesses to choose services that match both simple and complex infrastructure requirements.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

I would recommend Microsoft Azure for an organization that already depends heavily on Microsoft technologies. Azure works well with Windows Server, Microsoft 365, Microsoft Entra ID, SQL Server, and other Microsoft services. This integration can make user management, application deployment, and administration more convenient for the organization.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is a strong choice for organizations focused on AI, machine learning, data analytics, and Kubernetes. Google Cloud provides services for building and deploying machine learning applications and offers Google Kubernetes Engine (GKE) for managing containerized workloads. Its experience with large-scale data and distributed systems also contributes to its reputation in these areas.

### 4. What similarities did you observe among the three cloud providers?

AWS, Microsoft Azure, and Google Cloud all provide the basic infrastructure services needed to build modern cloud environments. Each provider offers virtual or managed compute services, different storage options, networking capabilities, and identity and access management tools. They also provide security features, monitoring tools, scalability, and services that allow organizations to deploy applications without maintaining all physical infrastructure themselves.

### Additional Observation

Although the names of the services are different, the basic functions provided by AWS, Azure, and Google Cloud are very similar. For example, EC2, Azure Virtual Machines, and Compute Engine all provide computing resources, while S3, Azure Blob Storage, and Cloud Storage are used for storing objects. Understanding these common concepts makes it easier for cloud engineers to work with different cloud platforms.
